# python-security-toolkit
A collection of cybersecurity tools developed in Python for security analysis, incident response and network monitoring.
They demonstrate practical security skills such as:
- File Integrity Verification
- Password Auditing
- Log Analysis
- Network Security
- Incident Response Concepts
- Python Programming

Tool	| Description:
- Hash Checker | Generate SHA256 hashes
- Password Auditor | Analyse password strength
- Log Analyser | Detect suspicious login activity
- Port Scanner | Identify open TCP ports
